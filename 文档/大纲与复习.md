# C 语言考试大纲与复习

> 本次测试重点考查考生综合运用从书本、教学视频等途径学到的 C 语言知识解决问题的能力，要求能够结合具体任务，将相关知识用于程序分析、编写和改进。正确理解常用语法和数据的表示方法，分析程序的执行过程，运用选择、循环、数组、函数等完成基本编程任务，并能根据题目提供的材料理解新概念、运用新规则。

## 考试内容与要求

### 一、C 语言基础

1. 了解程序、程序设计语言和算法的基本概念；理解算法的基本特性，以及顺序、选择、循环三种基本结构。

2. 掌握 C 程序的基本组成、`main` 函数、头文件、注释和语句的书写规则；了解编辑器、编译器、链接器和调试器各自的基本作用。

3. 理解 C 程序通常经过预处理、编译、汇编和链接生成可执行文件的过程，了解各阶段的主要任务及源文件、目标文件、库文件和可执行文件的区别。

4. 了解编译器进行词法分析、语法分析、语义分析和代码生成的基本思路，知道编译优化的基本用途；能结合简单示例理解标识符识别、语法检查和类型检查，不要求实现编译器。

5. 了解操作系统在程序装入、运行和结束过程中的基本作用，理解程序与进程的区别；了解进程地址空间、内存访问保护和文件管理的基本概念。

6. 了解 C 程序通过运行库与操作系统获取内存、访问文件和进行输入输出的基本关系；理解标准输入、标准输出和标准错误的基本用途，能区分文件路径中的相对路径与绝对路径。

7. 能用自然语言、流程图或伪代码描述简单算法；能区分编译错误、链接错误、运行时错误和逻辑错误，根据基本诊断信息及题意检查输入、处理过程和输出。

> **提示**：本部分将结合 C 程序的编译和运行过程，考查与程序设计有关的计算机基础知识。所以不管你们看什么视频，用什么教材，学习时应认真理解引言、导论及运行环境等内容，了解程序从源代码到实际运行所经历的过程，以及各类开发工具和操作系统在其中的作用。

### 二、数据类型与表达式

1. 掌握标识符、常量和变量的使用，整型、浮点型和字符型数据的表示与初始化；理解有符号与无符号整数的基本区别。

2. 理解位、字节、存储空间和地址的基本含义；掌握常用整数进制的表示与简单转换、字符与字符编码的关系、常用转义字符和 `sizeof` 运算。

3. 掌握算术、赋值、关系、逻辑、条件和逗号表达式，以及自增、自减和复合赋值运算；理解常用运算符的优先级、结合性和逻辑运算的短路规则。

4. 掌握整数除法、求余及常见类型转换；能判断表达式的类型与结果。理解按位与、按位或、按位异或、按位取反和移位运算，能按给定整数类型及位宽分析简单示例。

> **提示**：这部分注重学习和实际编程中容易忽略的基本规则与使用条件，不以生僻用法或刻意构造的复杂表达式设置难点。不要求推测含有未定义行为的程序会输出什么结果。

### 三、数据输入与输出

1. 掌握 `printf`、`scanf`、`getchar` 和 `putchar` 的基本用法；能使格式说明与参数类型正确对应，按要求完成数值、字符和字符串的输入输出。

2. 理解 `scanf` 中地址参数的含义，以及空白字符对常用输入格式的影响；能分析基本的输出宽度、精度和换行格式，识别常见输入输出错误。

> **提示**：输入输出不会在没有给出材料的情况下考察缓冲区、读写错误与流状态、部分读写、阻塞、原子性与持久化、终端输入机制与重定向等问题，试题如涉及上述内容，将提供必要的背景知识和规则说明，应能理解题目所给材料，结合已学知识，完成简单的程序分析、补全或编写任务。

### 四、选择结构与循环结构

1. 掌握 `if`、`if-else` 及其嵌套形式，掌握 `switch`、`case`、`default` 和 `break` 的使用；能正确表达复合条件，分析分支的执行过程。

2. 掌握 `for`、`while` 和 `do-while` 的执行顺序及使用方法，理解三种循环的区别；掌握循环嵌套，以及 `break` 和 `continue` 对程序流程的影响。

3. 能确定循环初值、循环条件和变量更新方式，分析循环次数及变量变化；能处理首次执行、零次执行和临界值等情况。

> **提示**：考试中所有程序不会使用 `goto` 语句，统一采用结构清晰、含义明确的书写方式，不采用生僻的技巧性写法或影响理解的省略形式。考查重点为程序逻辑、基本编程方法及所学知识的综合运用。

### 五、数组与字符串

1. 掌握一维、二维数组的定义、初始化和元素访问；理解下标范围及二维数组按行存放的次序，能完成数组遍历、统计和简单矩阵处理。

2. 掌握字符数组和字符串的表示及输入输出；理解字符、字符串、数组容量和字符串长度的区别，以及字符串结束标志 `'\0'` 的作用。

3. 掌握 `strlen`、`strcmp`、`strcpy` 和 `strcat` 的基本用法；能进行字符统计、字符串比较、复制、连接和简单变换，并检查数组边界及存储空间是否足够。

> **提示**：如果题目的考点为数组和字符串，那么是不会结合动态内存分配来考察的；但是如果题目的考点是动态内存分配，那么是有可能会结合数组与字符串来考察的。

### 六、函数

1. 掌握函数定义、声明、调用、形参与实参、返回值和 `void` 的用法；理解 C 语言按值传递参数的机制，能分析调用前后有关变量的变化。

2. 掌握函数的嵌套调用和数组作为函数参数的基本用法；理解递归的终止条件及调用过程，能编写简单递归函数。

3. 掌握局部变量与全局变量的作用域；理解变量的存储期、静态局部变量的特点，以及声明与定义的区别。

> **提示**：这部分以常规函数的定义与调用为考查对象，重点考查参数传递、返回值、递归过程及变量的作用域和存储期。不涉及利用宏定义程序段实现函数，也不涉及利用函数指针模拟其他函数高阶用法等知识，函数指针的基本概念和简单用法归入指针及其应用部分考查。

### 七、指针及其应用

1. 掌握地址、指针变量、取地址运算和间接访问；能正确声明、初始化和使用指针，理解空指针及有效访问的条件。

2. 掌握通过指针访问一维数组和字符串、用指针参数访问或修改实参所指对象的方法；理解指针运算与所指类型的关系，以及数组名在常见表达式中的转换。

3. 理解字符数组与字符指针、指针数组与指向数组的指针的区别；能分析简单的二维数组地址表达式。了解二级指针、函数指针、返回指针的函数及命令行参数的基本用途。

> **提示**：这部分重点考查指针所指对象、访问范围及指针操作对数据的影响，程序采用含义明确的声明和表达式，不以复杂声明、多层间接访问或运算符的刻意嵌套设置阅读障碍。二级指针、函数指针、返回指针的函数及命令行参数仅要求理解基本含义、辨认简单用法，不要求利用这些机制设计复杂程序。

### 八、结构体与其他自定义类型

1. 掌握结构体类型及变量的定义、初始化和成员访问，掌握结构体数组和结构体指针的基本应用；能区分并正确使用成员运算符 `.` 和 `->`。

2. 理解结构体嵌套，以及结构体变量、结构体指针作为函数参数的用法；能完成简单记录的查询、统计与排序。

3. 理解枚举类型和 `typedef` 的基本用法；了解共用体的含义及其与结构体的存储区别。结构体具体占用空间的计算按题目给定的类型大小和布局规则进行。

> **提示**：这部分重点考查利用结构体组织数据、访问成员及处理简单记录的能力，不涉及位域、复杂的嵌套声明或利用共用体进行跨类型的数据解释。枚举和 `typedef` 以基本用法为主。涉及结构体存储布局和占用空间计算时，题目将给出必要条件，不要求记忆特定编译环境下的布局规则。

### 九、编译预处理与程序组织

1. 掌握 `#include` 和不带参数的宏定义；理解宏替换、带参数的宏与函数调用的区别，能分析简单宏展开及括号对结果的影响。

2. 了解条件编译和多文件程序的基本组织方式，了解头文件、外部声明和文件作用域下 `static` 的基本用途。

> **提示**：这部分重点考查宏替换、文件包含及多文件程序中声明与定义的关系。带参数的宏仅涉及简单展开及括号使用，不考查利用宏组织复杂程序，也不涉及字符串化、记号拼接或多层嵌套的宏展开。多文件程序以理解各文件之间的关系为主，不要求掌握复杂的工程配置和构建工具。

### 十、动态内存分配与指针应用

1. 掌握 `malloc` 和 `free` 的基本用法，能根据数据类型和数量确定所需空间，检查分配结果并在适当时机释放空间；理解动态申请的空间与指针变量的关系，能识别越界访问、内存泄漏、重复释放和释放后访问等常见问题。

2. 能按照题目给定的操作规则，利用指针、数组或结构体管理动态申请的存储空间，完成数据的保存、读取和删除，并正确更新相关指针和计数变量。所需的存取规则和操作要求由题目明确给出。

> **提示**：这部分仅涉及 `malloc` 和 `free`，不考查 `calloc`、`realloc` 及内存分配器的内部实现。题目将明确给出数据的存取规则和操作要求，重点考查根据规则申请和释放空间、通过指针访问数据，以及在操作过程中维护指向关系的能力，不要求预先掌握特定的数据组织方式或背诵成套的实现代码。

### 十一、文件操作

1. 理解文本文件、二进制文件和文件类型指针的基本概念；掌握 `fopen`、`fclose` 及常见打开模式，能检查文件是否成功打开。

2. 掌握字符、字符串和格式化方式的基本文件读写；理解 `fread`、`fwrite` 的用途及返回值，能根据读写结果控制处理过程。

3. 理解文件结束与读写错误的区别；了解 `fseek`、`ftell` 和 `rewind` 的作用，能分析给定的简单文件定位示例。

> **提示**：这部分重点考查根据任务选择文件打开模式、完成基本读写和定位操作，并正确使用函数返回值。涉及读写错误、流状态、部分读写、阻塞、原子性与持久化等问题时，题目将提供必要材料，要求结合材料和已学知识分析简单程序，不要求预先掌握相关底层机制。

### 十二、综合程序设计与材料阅读

1. 掌握累加、累乘、计数、求最值、整数数位处理、素数判断、简单递推和枚举等基本方法；了解顺序查找、二分查找、冒泡排序和简单选择排序的基本概念，了解各方法的适用条件。

2. 能根据题意选择数据类型和组织方式，将处理过程分解为函数，编写完成基本任务的程序；能追踪变量及数据变化，补全关键语句，指出并修改常见错误。

3. 能从文字、表格和示意图中提取条件，将给定规则转化为计算步骤或程序。材料题涉及的新增概念、规则及必要的计算机组成背景由题目给出，不要求提前记忆本大纲所列知识点之外的专门知识。
